# Task 8: Simple Sales Dashboard (Power BI)
## 📂 Contents
- **Superstore_Sales_Synthetic.csv** — Dataset used for the dashboard.  
- **TASK_8_Simple_Sales_Dashboard_PowerBI.pbix** — Power BI project file 
- **TASK_8_Simple_Sales_Dashboard_PowerBI.pdf** — Final exported dashboard report.  

## 📊 Dashboard Visuals
1. **Line Chart** — Sales over Months  
2. **Bar Chart** — Sales by Region  
3. **Donut Chart** — Sales by Category  
4. **Insights (Text Boxes)** — Key findings highlighted  

## 📌 Insights
- **Top Region**: Region with the highest sales contribution.  
- **Best Category**: Category generating the most revenue.  
- **Peak Month**: Month with maximum sales.  
- **Trend Analysis**: Comparison of last 3 months vs. previous 3 months.
